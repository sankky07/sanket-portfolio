# Sanket Kumar Sahu — Professional Interactive Portfolio

A minimalist software-engineering portfolio designed around professional presentation with small, intentional interactive experiences.

## Included

- Compact Dynamic-Island-inspired navigation
- Smooth Lenis scrolling
- Dark / light mode
- Editorial DESIGN. / ENGINEER. / BUILD. hero
- Interactive Java security-review challenge
- Interactive technology stack builder
- Project case-study modal with architecture flow
- Interactive terminal with navigation commands
- Hidden Easter egg
- Resume-grounded professional summary, skills, experience, projects and education
- Responsive desktop / mobile layouts
- Reduced-motion accessibility support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Resume

If you want a downloadable resume CTA, place the final PDF at:

`public/resume.pdf`

Then add the CTA to the contact section.
